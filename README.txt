PAINT HAPPENS — FREE PORTFOLIO WEBSITE

1. Open index.html in a web browser to preview.
2. The exact uploaded logo is included in images/paint-happens-logo.png. The white outer background was removed for use on black.
3. The four category buttons work now. Galleries are intentionally empty until you add real project photos.
4. Put photos in the images folder (e.g. living-room.jpg).
5. Edit the galleries section near the bottom of index.html. Example:
   interior:{title:'Interior Painting',description:'Walls, ceilings, trim and interior transformations.',photos:[
     {file:'images/living-room.jpg',caption:'Living room — after'}
   ]},
6. IMPORTANT: Replace YOUR_EMAIL_HERE in the contact button with your actual email before publishing. No phone number or email was assumed.
7. Upload index.html and the entire images folder to a static hosting service such as GitHub Pages or Cloudflare Pages.
8. Only generate and print a QR code after the website is publicly published and tested on a phone.

The design is a working starter site, not a live hosted website.
